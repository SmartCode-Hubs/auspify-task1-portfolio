# Auspify Task 1 - Personal Portfolio Website

A modern, responsive, full-stack personal portfolio built during the 4-week practical learning program at Auspify Technologies. This project showcases my skills, projects, and provides a secure contact form connected to a MongoDB database.

## ✨ Key Features
- **Modern Dark UI:** Built with Tailwind CSS, featuring glassmorphism elements and smooth Framer Motion animations.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens.
- **Project Showcase:** A dynamic grid displaying my full-stack, AI, and data engineering projects.
- **Functional Contact Form:** A secure API endpoint that validates user input and saves messages directly to a MongoDB database.
- **CV Download:** A quick download link for my resume.

## 🛠️ Tech Stack
- **Frontend:** React.js, Tailwind CSS, Framer Motion, React Icons, Vite
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas (Mongoose)
